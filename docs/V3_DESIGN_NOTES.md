# Personal Website V3 — Design Notes

## Design objective

Clear hierarchy × personal identity × crafted, not templated.

The site remains recruiter-first and preserves the existing information architecture, but the homepage now uses a more distinctive visual grammar instead of repeated template cards.

## Visual system

- Sans-serif only: Inter + Noto Sans TC
- Light default with dark-mode toggle
- Black / white / deep blue / electric blue
- Signature elements: blue dot, thin rule, numeric section index, asymmetric spacing
- Restrained outline icons
- No serif display type, neon styling, typing effects, particle backgrounds, or excessive parallax

## Homepage refinements

1. Personal-first hero with a stronger `Tina Tai.` identity lockup
2. Medium portrait composition with offset blue plane and technical line details
3. Editorial credibility strip instead of a dashboard box
4. Three case studies with different compositions but one visual language
5. Experience section shown as clean career rows rather than resume cards
6. Research displayed as a visual credibility layer
7. About section emphasizes the personal journey and point of view
