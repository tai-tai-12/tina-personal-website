## Work index vs. project detail hierarchy
- The Work landing page remains open, left-aligned, and index-like.

## Case-study reading layout
- Project Snapshot now sits in a light transition band between hero and narrative.
- The reading shell is moved inward and narrowed.
- Sidebar width is reduced and offset from the far-left page edge.
- Sidebar remains capped at five primary entries.
- Detail H2 sections use a distinct editorial hierarchy: Problem / Role & Scope / System / Evidence & Depth / Takeaway.

## Responsive / dark mode
- Mobile hero remains centered and compact.
- Metrics switch to a 2×2 layout on small screens.
- Sidebar disappears below tablet width.
- Dark-mode gradients keep project imagery subtle rather than image-led.
