# Update the live site to V4

Your GitHub Pages deployment already works, so you do **not** need to recreate the repository or Pages settings.

## Recommended: GitHub Desktop
1. Download and unzip the V4 deployment package.
2. Open the local folder that is connected to your existing `tina-personal-website-v2` GitHub repository.
3. Replace the old website files with the contents of the V4 folder.
4. In GitHub Desktop, review the changed files.
5. Commit with: `Refine typography and color system for V4`
6. Click **Push origin**.
7. Open GitHub → repository → **Actions**.
8. Wait for **Build and deploy** to turn green.
9. Refresh your live GitHub Pages URL.

## Important
Do not create a new Pages workflow and do not change Settings → Pages. The existing GitHub Actions deployment should continue to work.
