# Tina Tai Personal Website — V7.0

**Release:** Recruiter-Curated Portfolio & Visual System Lock

V7.0 consolidates the strongest decisions from V6.1–V6.5 into one production-ready portfolio baseline. The release does not add new page types; it improves how recruiters scan the site, how research is discovered before a click, and how repeated UI patterns behave across Work, Experience, Education, Research, About, and Footer.

Key updates:
- One top-level page-header system across Work, Experience, Education, Research, and About.
- Research context label updated to `RESEARCH PROFILE`; all top-level page intros now use the same divider, typography scale, and spacing rhythm.
- Project/research proof pills replaced with lighter evidence rails so metrics read as information rather than buttons.
- Selected Work title wrapping, text/image balance, and CTA weight refined for large screens.
- Thoracic Aorta research preview rebuilt at the same 1200×750 ratio and editorial visual level as the Brain Tumor research preview.
- Aorta landing copy is self-contained enough to understand the project without opening the detail page; the detail page remains the deeper research note.
- Education density reduced so the first degree appears sooner; Experience timeline metadata remains easy to scan.
- Footer email uses regular/medium weight; LinkedIn and Resume are now peer utility actions instead of mismatched filled/unfilled buttons.
- Latest PM resume remains bundled at `static/resume/Shih-Ting_Tai_Resume.pdf`.
