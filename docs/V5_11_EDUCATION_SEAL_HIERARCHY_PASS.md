# V5.11 — Education Seal & Hierarchy Pass

## Changes
- Replaced the text-only `CMU` and `NYCU` institution markers with the user-provided university seals/emblems.
- Made each seal clickable to the corresponding university website.
- Standardized every education entry to the same two-line institution hierarchy:
  1. University name
  2. School / institute / department name
- Added dedicated vertical spacing so the school name and academic unit no longer appear on the same line.
- Preserved the existing degree, dates, location, focus areas, and project/research links.
- Added mobile sizing for the institutional seals and two-line hierarchy.
