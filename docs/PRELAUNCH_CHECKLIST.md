# Pre-launch Checklist

## Required before first public launch

- [ ] Open the homepage on desktop and mobile.
- [ ] Confirm the English / 中文 toggle works.
- [ ] Confirm light / dark mode works.
- [ ] Click every navigation link.
- [ ] Open every case study.
- [ ] Open the Resume button and verify the PDF is current.
- [ ] Test LinkedIn and Email links.
- [ ] Confirm no private phone number appears publicly unless intentionally added.
- [ ] Review project text for confidential / proprietary details.
- [ ] Confirm all published metrics are ones you are comfortable making public.
- [ ] Check spelling of organization names, conference names, and awards.
- [ ] Confirm exact publication titles / DOI links before replacing the current placeholders on Research.

## Before adding tinatai.com

- [ ] Purchase the domain.
- [ ] Verify the domain in GitHub account settings (recommended).
- [ ] Add the four GitHub Pages A records.
- [ ] Add the `www` CNAME to `YOUR-GITHUB-USERNAME.github.io`.
- [ ] Set `tinatai.com` under repository Settings → Pages → Custom domain.
- [ ] Wait for the DNS check to pass.
- [ ] Enable Enforce HTTPS.

## Later polish

- [ ] Replace the current portrait with the newer professional portrait.
- [ ] Replace CSS project visuals with approved real / recreated visuals.
- [ ] Add Open Graph image.
- [ ] Add verified publication links.
- [ ] Replace Case Study 03 when a stronger CMU analytics / tech project is ready.
- [ ] Surface Writing only after 2–3 strong articles exist.
