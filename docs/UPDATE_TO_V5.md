# Update Current GitHub Site to V5 / Round 1 Visuals

Your repository should remain named `tina-personal-website`.

1. Download and unzip the V5 package.
2. In GitHub Desktop, open the current `tina-personal-website` repository.
3. Choose **Repository → Show in Finder**.
4. Copy the contents of the V5 folder into that repository folder.
5. Replace matching files when macOS asks.
6. Do **not** delete or replace the hidden `.git` folder.
7. Return to GitHub Desktop.
8. Commit message: `Add Round 1 portfolio visuals`.
9. Click **Commit to main**.
10. Click **Push origin**.
11. On GitHub, open **Actions** and wait for **Build and deploy** to turn green.
12. Hard refresh the live site with `Cmd + Shift + R`.
