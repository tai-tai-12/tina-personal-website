# V6.1 — Readability, Portrait Integration & Visual Polish

## Why this release

V6 strengthened product judgment and evidence. V6.1 is a visual refinement release focused on readability and photographic integration rather than adding new content.

## Typography and hierarchy

- Increased the minimum readable size of supporting metadata across Experience, Work case studies, Research, Education, and the footer.
- Experience dates and locations are materially larger while still remaining secondary to role titles.
- Increased company / organization labels, body copy, bullets, sub-section labels, links, and scope labels.
- Slightly reduced page-H1 maximum size so hierarchy comes from scale plus weight/color rather than extremely large title-to-metadata contrast.
- Case-study sidebar labels, At-a-Glance labels, figure captions, technical labels, and capability text are easier to read.

## Homepage portrait integration

- Kept the V5.30/V6 portrait photograph itself.
- Removed the offset blue backing plane that made the portrait read like a separate card.
- Removed the visible border treatment.
- Enlarged the portrait slightly and aligned it more naturally with the hero copy.
- Replaced the offset card effect with a very soft blue radial wash and restrained shadow.
- Increased nearby supporting text slightly so the photo and copy have more balanced visual weight.

## About photo

- Replaced the About documentary image with the exact newly supplied IMG_6287.JPG source, web-optimized without generative editing.
- Preserved the 3:2 composition so both the presentation screen and speaker remain visible.
- Removed the heavy framed-photo treatment in favor of a lighter documentary presentation.

## Visual QA focus

- Experience: date/location/company/body/bullets no longer fall below a comfortable reading hierarchy on wide desktop screens.
- Work cases: micro-navigation and explanatory labels are no longer 8–10 px in the final cascade.
- Research/Education: supporting metadata remains secondary but readable.
- Mobile: hierarchy compresses proportionally rather than restoring tiny metadata.
