# V5.22 — Case Study Editorial System

## Scope
This version redesigns only the three Selected Work detail pages. Other site sections remain on the V5.21/V5.20 system.

## Key changes
- Removes the oversized standalone hero image from the top of each case study.
- Uses the project image as a subtle, gradient-masked hero atmosphere instead.
- Adds a compact metric rail and a four-part Project Snapshot.
- Narrows text measure while allowing explanatory visuals to break wider.
- Reduces large-figure prominence and caps explanatory image height.
- Reworks section hierarchy with numbered editorial headings.
- Keeps MIDL + IEEE AMLDS together as research evidence for the product case.
- Adds lightweight Previous / Next / All Work navigation at the bottom.
- Mobile collapses to one column without sticky navigation.

## Design principle
Generated visuals explain concepts. Real photos prove that events and research outputs happened.
