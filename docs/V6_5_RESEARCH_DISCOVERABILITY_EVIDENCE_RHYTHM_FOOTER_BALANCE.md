# V6.5 — Research Discoverability, Evidence Rhythm & Footer Balance

## Release goal
Improve research discoverability without forcing clicks, replace pill-heavy evidence UI with a cleaner information rhythm, rebalance top-level page density, and make footer contact actions visually clear and neutral.

## Implemented
- Added one shared top-level page-header grammar for Work, Experience, Education, Research, and About.
- Added the missing Research divider and standardized header spacing across top-level pages.
- Increased eyebrow/icon readability while slightly containing H1 scale.
- Changed Research page context from `SELECTED RESEARCH` to `RESEARCH PROFILE` / `研究概覽`.
- Reduced secondary Research heading scale so section headings no longer compete with the page title.
- Replaced pill-heavy project/research/highlight proof UI with an evidence-rail system using restrained separators.
- Kept Work/Research proof points readable without looking like clickable buttons.
- Rebuilt the Thoracic Aorta preview visual as a stronger dark editorial composition: one dominant 3D aorta reconstruction plus supporting CT views.
- Strengthened the Aorta landing copy so the project is understandable without opening the detail page.
- Tightened Education hero-to-content spacing and reduced the visual dominance of the credentials rail.
- Removed footer action asymmetry: LinkedIn and Resume now use the same closing-action treatment.
- Kept the raw email visible and clickable, but removed heavy emphasis; email is not converted into a button.
- Preserved one primary email only.

## Content guardrails
- No changes to unresolved AIMISAL chronology.
- No cross-mixing of brain-tumor cohort or evaluation definitions.
- Aorta canonical metrics remain 308 CT cases, mean AUC 0.95, and overall DSC 0.782.

## V6.5 principle
Resume = qualification. LinkedIn = completeness. Portfolio = interpretation, judgment, curated evidence, and visual explanation.
