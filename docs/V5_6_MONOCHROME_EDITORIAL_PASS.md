# V5.6 — Monochrome Editorial Pass

## What changed
- Removed the mixed four-item credibility strip below the hero. Education, project scale, and research recognition now live in the sections where they belong.
- Tightened Hero → Selected Work spacing.
- Reworked the CTA system: near-black primary actions, outline secondary actions, compact project buttons, and restrained blue interaction states.
- Replaced text-heavy project infographics with illustration-first vector art. Homepage visuals contain almost no explanatory text; details live in the case-study copy.
- Rebuilt the Work landing page as three editorial project rows with custom monochrome visual cues.
- Simplified detailed clinical/product and AI-cascade SVGs so they no longer look like presentation slides.
- Reduced card radii, shadows, gradients, and decorative UI treatments to remove template-like styling.
- Tightened section spacing and typography hierarchy.
- Preserved the existing black/white/blue brand: monochrome surfaces, electric blue only as a controlled accent.

## Design principle
**Words explain. Visuals orient. Buttons move the reader forward.**

## Deployment
Copy the contents of this folder into the existing `tina-personal-website` repository, replace matching files, commit, push, and wait for GitHub Actions to finish.
